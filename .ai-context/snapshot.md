## Project Overview

**AI Context Standard** — 让代码库具备知识自增长能力的开源框架。
核心思想：让 AI coding agent 从"孤立空间的天才"变成"持续在场的团队成员"。
关键机制：知识通过 git 传播，和代码享受同等待遇。

## Architecture

### 核心流程
```
开发对话 → agent 识别知识 → 写入 buffer → 用户暂停 → /lore-compact(可选) → /lore-digest flush → increments
  → 定期 /lore-evolve → 编译为 snapshot → git push → 全团队继承
```

### Hooks 触发链
- **Stop** → 检测 buffer 条目数 → soft(5)/lore-compact(8)/hard(15) 三级触发
- **PostToolUse (git commit)** → 提取 commit 知识 → 锁定 buffer → flush
- **SessionStart** → 加载 snapshot + /lore-health 校验
- **SessionEnd** → 紧急 flush
- **PreToolUse** → 拦截 snapshot 直接编辑 + 编辑前知识提示

## Key Decisions

### buffer flush 阈值基于知识条目数（2026-04-23）
- 初始设计基于"对话轮数"，后发现不准确
- 按条目数更直接反映知识积累的实质
- soft=5, compact=8, hard=15

### 快照禁止直接编辑（2026-04-23）
- 只允许通过 /lore-evolve 编译产生
- 保证快照质量一致性

## Constraints

- stop-flush.sh 和 config.yaml 中的阈值必须保持一致
- 阈值变更需要同步更新所有文档引用（architecture.md, README, spec）
- hook 脚本中 [LOCKED:] 标记防止 commit flush 和 stop flush 重复触发
